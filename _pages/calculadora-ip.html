          01 / Calcular

          IP, máscara y CIDR

          Una /24 IPv4 tiene 256 direcciones. En una LAN estándar quedan 254 hosts tras excluir red y broadcast. Una /31 punto a punto y una /32 se tratan de forma distinta.

          02 / Planificar

          El tamaño que necesitas

          VLSM adapta cada bloque a su demanda. El perfil cloud descuenta las reservas del proveedor. El mapa muestra espacio asignado a subredes, no hosts ocupados.

          03 / Comprobar

          Sin solapamientos ni huecos

          Comprueba un plan antes de conectar redes. La agregación elimina duplicados y bloques contenidos, y une redes solo cuando puede representar exactamente el mismo espacio.

          Criterios del cálculo

          • IPv4 estándar: se excluyen red y broadcast hasta /30. En /31 se muestran los dos hosts para enlaces punto a punto; /32 representa una dirección.
          • Azure y AWS IPv4: los perfiles descuentan las primeras cuatro direcciones y la última. Azure admite aquí /2–/29 y AWS /16–/28, según sus límites de subred.
          • IPv6: admite prefijos /0–/128 y muestra el tamaño y los límites exactos del bloque. No hay broadcast. Las reservas de anycast y las restricciones de los proveedores requieren revisar el caso concreto.
          • La clasificación es orientativa: identifica algunos rangos de uso especial de la IP introducida. No comprueba conectividad, disponibilidad pública, asignaciones de IANA ni políticas de un despliegue.
          • Privacidad: esta página no carga analítica, no envía tus redes ni guarda un historial. Solo se copian o exportan resultados cuando pulsas sus botones.
